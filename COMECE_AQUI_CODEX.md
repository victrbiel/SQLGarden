# Manutenção do SQLGarden

SQLGarden foi desenvolvido por Victor. É um cliente macOS aberto sob MIT.
Leia README.md, INSTALACAO.md, CONTRIBUTING.md e docs/ARQUITETURA.md.

Preserve o cliente nativo SwiftUI/AppKit, os dados dos usuários, as credenciais
no Chaves e as artes de Design/SQLGarden-Visual-Kit. O app não incorpora Python.
Use os scripts reais para testar, compilar e empacotar. Registre evidências
precisas em docs/VALIDACAO_MAC.md. Nunca confunda cross-compilation com teste
físico em outra máquina. Não inclua perfis, segredos, volumes ou dados locais
nos arquivos de distribuição. Não publique externamente sem pedido do mantenedor.
